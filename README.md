## 이 자료를 읽을 때

1. **곳수를 섞지 않습니다.** 38·43·37은 서로 다른 집합입니다. 한 문장에 섞으면 부호가 갈립니다.
   인구 1만 명당 출석은 43곳이면 57.4명, 38곳이면 59.2명입니다. 같은 자료인데 값이 다릅니다.
2. **출석은 사람 수가 아니라 연인원입니다.** 한 분이 한 해에 50번 나오시면 50으로 셉니다.
3. **함께 움직였다까지만 말합니다.** 이 자료는 원인을 말하지 않습니다.
4. **기록과 현장은 다를 수 있습니다.** 모든 기록은 교당이 원티스에 스스로 입력한 것이고,
   집계·개인 도장·법회 기록이 사실상 한 뿌리로 보입니다. 장부끼리 맞는다는 것이 현장의 보증은 아닙니다.
5. **정책 결론은 담지 않았습니다.** 「그러므로 무엇을 하자」는 2차 보고서의 몫입니다(규약 5-1).

## 제4판이 제3판에서 고친 것

제3판(2026-08-21)의 수치를 원자료에서 처음부터 다시 계산해 전수 검증했습니다 —
본문 수치 755개 · 그림 라벨 2,366개 · 부록 표 셀 7,653칸.
**일치 92 · 불일치 14 · 재현 불가 7**이었고, 열두 자리를 고쳤습니다.

주요한 것 다섯:

- 부록 표 두 개에 다른 계열이 실려 있었습니다 — 「군법회 출석」 표 102칸이 정례5종 값,
  「청소년 출석」 표 42칸이 명부 교도수였습니다. 그림 자체는 옳았습니다.
- 그림 36·39가 [43곳] 표기인데 38곳 계열이었습니다.
- 관리·미관리 교도의 역전 시점이 원기106년이 아니라 **원기108년**입니다.
- 「청소년 담당 교당 63곳」은 「63**건**」입니다(교당 × 법회 종류). 담당 교당 수로는 26곳 → 10곳입니다.
- 교무 총수 54 → 47명은 원기97 → **원기108**입니다. 원기109·110은 아직 자료가 없습니다.

고치지 않고 남긴 것 — 6-1의 두 장부 상관 0.794, 역산 개설 −44%, 원기105 낙폭 −43.8%는
값을 만든 조건을 특정하지 못해 그대로 두었습니다. 방향은 재확인되나 소수점 값 단독 인용은 미룹니다.

자세한 것은 총합본 11-6 「제4판 정정 이력」에 있습니다.

- 원기 = 서기 − 1915 (원기97 = 2012 · 원기110 = 2025)
- 실질 금액은 원기110년 돈으로 환산했습니다(원기97년 1원 = 원기110년 1.27원)
